Key details in this design

  • Sidebar height matches the calendar card — doesn't grow beyond the page viewport
  • Meals list scrolls internally — page itself never scrolls for the sidebar
  • Search bar filters the list in real time as you type
  • Drag handle (⠿) on each meal card signals it's draggable
  • Meal description shown as subtitle when available
  • Drop zone highlight (dashed border) appears on cells when dragging over them
  • "+ Add new meal" footer button — quick shortcut to the Meals Library page
